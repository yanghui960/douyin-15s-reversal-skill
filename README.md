# douyin-15s-reversal-skill

> 我的专属 SKILL：把一段短故事一键做成 **抖音 15 秒竖屏反转短剧分镜包**。

## 它做什么

输入一段剧情，直接产出可拍摄 / 可喂 AI 的完整分镜包：

- 4 拍结构（钩子 → 误读 → 反转 → 落地）
- 12 镜分镜表（景别、焦距、运镜、时长、画面、声音）
- 音效三层配置 + BGM 急停设计
- 每镜出图 / 视频 / 配音提示词（接即梦、可灵、剪映）

## 我的专属设定

- 人物严格 2-3 人
- 台词直白带情绪，动作指令式描写
- 9:16 竖屏，资产锚点全片统一

## 目录

```
├── SKILL.md          ← 技能本体（工作流定义）
└── examples/
    └── 陈明传纸条-抖音15s-AI分镜包.md   ← 完整示范案例
```

## 使用

把 `SKILL.md` 放进你的 AI 技能目录（如 `.user_skills/douyin-15s-reversal/`），然后对 AI 说：
"把这个故事做成 15s 抖音分镜：<你的剧情>"
